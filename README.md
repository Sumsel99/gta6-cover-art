Sunset Cover Studio turns any photo and caption into GTA 6-style cover art — bold multi-panel layouts, heavy typography, and a sunset/neon Vice City grade. It exports PNGs at 1080×1080, 1080×1350, and 1920×1080, runs fully offline in a desktop browser, and your photos never leave your machine.

## Run it

```sh
node serve.ts
```

Open http://localhost:8080, drop in a photo, pick a layout, edit the caption, then export your PNG.
